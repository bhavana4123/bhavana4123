## 🚀 Featured Projects

### ♻️ WasteWise AI — *turning trash into (calculated) treasure*
`Python` `FastAPI` `React` `TypeScript` `Three.js` `AWS Lambda` `AWS Amplify`

A full-stack, serverless platform that pulls together **6 scientific datasets** to evaluate anaerobic digestion, pyrolysis, and gasification for waste-to-energy. Source-backed calculations, a live deployment, and **333 automated tests** keeping the backend honest. ✅

### 🔐 Phishing Detection MLOps System — *catching bad links at scale*
`Python` `FastAPI` `Scikit-learn` `MLflow` `Docker` `AWS ECR` `MongoDB` `GitHub Actions`

An automated **4-stage pipeline** (ingestion → validation → transformation → training) that detects phishing URLs using **30+ network features**. Models are versioned with MLflow and DagsHub, served via FastAPI, and shipped to AWS ECR through CI/CD. Push code, grab a snack, model deploys itself. 🍿

### 🌊 Kafka Transaction Processing System — *100+ transactions a minute, zero drama*
`Spring Boot` `Kafka` `JPA` `H2`

Built during the **JPMorgan Chase Software Engineering Virtual Experience**. An event-driven backend with Kafka producers and consumers, transaction validation, database persistence, and an external REST API for incentive calculation. Used embedded Kafka diagnostics to hunt down consumer group lag. 🕵️‍♀️

### 🎬 Movie Recommendation System — *"what should I watch tonight?" solved*
`Python` `NLP` `Cosine Similarity` `Streamlit` `TMDB API`

Content-based recommender on the TMDB 5000 dataset using NLP vectorization across genres, cast, crew, and keywords. Returns the **top 5 similar movies** with sub-second inference and live poster fetching. 🍿
